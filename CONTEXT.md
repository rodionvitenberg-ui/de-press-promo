# CONTEXT — de-press.co

Ubiquitous language of the product. Glossary only — no implementation details.
Source of truth for domain meaning: README («Проект de-press.co»).

## Product

**de-press.co** — некоммерческая эмпатичная платформа, «тихая гавань» для людей, которым эмоционально тяжело. Альтернатива токсичным соцсетям: вместо лайков, рейтингов и публичных реакций — тишина, эмпатия и контроль автора.

**Не медицина.** Не замена терапии и не экстренная помощь. Кризис → 112/103 и страница `/safety`.

## Public layer (что видит читатель)

**Облачко** — единица публикации автора; публичная часть строится по инварианту:
`[монолог] [Я слышу тебя] [Тихие фразы] [Похожая история]`.

**Монолог** — текст автора о своём состоянии; основное содержимое облачка.

**«Я слышу тебя»** — единственная публичная реакция читателя; не лайк, не оценка.

**Тихие фразы** — короткие поддерживающие реплики; мягкая альтернатива комментариям.

**Похожая история** — чужой опыт, похожий по настроению; связь через резонанс, не через обсуждение.

## Author layer (инструменты автора)

**Pulse** — индикатор того, что историю слышат (без публичных метрик и рейтингов).

**Hearers** — те, кто услышал историю; видимы только автору.

**Приватные облачка** — записи автора, не опубликованные публично.

**Inbox** — приватные запросы на контакт, видимые только автору.

**Outreach** — инициатива автора: только автор инициирует чат (accept или Author Outreach).

## Safety

**/safety** — кризисная страница: признаки кризиса, шаги самопомощи, телефоны 112/103; доступна с любого экрана продукта.

**Anti-Panic** — режим продукта, важнее ленты и realtime.

**Helper** — человек, помогающий услышать; не терапевт по умолчанию.

**Emotional maps** — «карта эмоций/травм»; только на устройстве пользователя (ZK), не на сервере.

## Principles (не ломаются)

1. Нет публичных лайков / рейтингов страдания.
2. Нет публичных комментариев под историей.
3. Чат инициирует только автор.
4. ИИ всегда помечен; без диагнозов и toxic positivity.
5. Emotional maps — только device (ZK).
6. Anti-Panic важнее ленты и realtime.
7. Кризис → 112/103 и `/safety`.
8. Helper ≠ терапевт по умолчанию.
