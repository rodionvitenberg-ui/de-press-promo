## Решение зафиксировано

- Точка отсчёта — git-тег `pre-originalize` (ветка `variant/dawn-art`).
- Цель: к деплою в репо не остаётся минифицированных вендоров (`public/static/js/*`) и HTML-снимков (`markups/`) — только собственный код.
- Студию и приложение de-press не трогаем.

## Целевая архитектура

```
app/(legacy)/                        routes + metadata (SSG 10 локалей)
components/
  pages/{home,about,values,contact}.tsx   JSX вместо markups/* (DOM и классы 1:1)
  runtime/                            собственный рантайм вместо main.js
    SiteRuntime.tsx                   client-обёртка в (legacy)/layout
    capabilities.ts                   замена Detectizr/Modernizr
    loader.ts, menu.ts, scroll-engine.ts, fx-letter.ts,
    cases-hover.ts, cookie-bar.ts, transitions.ts
  legacy/glscene/                     наш TS/three — подключается прямым импортом
i18n/                 те же 10 словарей (ключ = RU-строка) + t(), <Fx>, <LangSwitcher>
public/static/css/    main.css (отформатирован) + depress.css
```

Ключевые упрощения, которые даёт оригинализация:

- `window.SceneGL` + Proxy-патч + `data-boot-src` уходят: glscene импортируется напрямую, JSON прокидывается прямо.
- Highway заменяется нативной навигацией Next.
- GSAP/TweenMax не нужны: CSS + RAF, сплайны уже в `glscene/splines.ts`.

## Риски и запасной рубеж

- **Скролл-хореография**: побайтового паритета с GSAP-таймингами не будет — критерий «визуальный паритет» по 12–14 состояниям, отличия фиксируем осознанно.
- **Запасной рубеж**: если интеграция рантайма (Фаза 3.2) затянется — деплой возможен на состоянии Фазы 3.1 (JSX + легаси-рантайм уже работают и проверены), рантайм доделывается после выката. Это осознанное решение, а не откат.
- **Cookie-бар и `js-typed/js-table-expand/js-sentences`** — малые, но точные поведения: реализуются по контракту, не «на глаз».
